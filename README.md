# Lead Engine

## Problem

Sales teams lose opportunities because prospect research and qualification are inconsistent and time-consuming.

## What It Does

The Lead Engine discovers prospects, filters and enriches them, verifies contact information, qualifies prospects with AI, scores them using deterministic rules, and routes approved leads for outreach.
